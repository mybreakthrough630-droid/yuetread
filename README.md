# 粵讀 · 智能提詞器

一個本地優先、零依賴的粵語同步提詞網頁應用。

## 運行

直接打開 `index.html`，或在本目錄啟動靜態伺服器：

```bash
python3 -m http.server 8080
```

然後瀏覽 `http://localhost:8080`。桌面本機測試可以使用 localhost；Android 手機必須使用已部署的 HTTPS 網址，不能經 `http://電腦IP:8080` 使用咪高峰。

## Android 安裝及權限

1. 使用最新版 Android Chrome 開啟 HTTPS 網址，避免 WhatsApp、Facebook 等內置瀏覽器。
2. 第一次按「開始朗讀」時，允許網站使用咪高峰。
3. 網站出現「安裝到手機」後按下安裝；亦可從 Chrome 選單選擇「安裝應用程式」。
4. 如果曾拒絕咪高峰，到 Chrome「網站設定 → 咪高峰」重新允許。

應用程式會優先使用 `yue-Hant-HK` 辨識粵語；Android 裝置不支援時會自動切換到 `zh-HK` 兼容模式。

## 功能

- 粵語口語輸入時即時生成可修改的普通話書面語
- 粵語及普通話稿件各支援最多 20,000 字
- 粵語口稿與普通話書面語雙向生成
- 本機口報文稿庫，可儲存、載入和刪除文稿
- TXT、SRT、VTT 匯入及音訊播放
- 每句字幕即時編輯、增刪
- 麥克風粵語識別、朗讀進度和語速估算
- 逐字朗讀追蹤：未讀、正在辨識、已跟上的文字以不同顏色顯示
- 提詞區可切換粵語／普通話字幕，每個漢字下方對齊顯示粵拼或普通話拼音
- 使用瀏覽器語音合成朗讀目前粵語或普通話句子
- 根據語速及匹配進度自動切換提示詞
- 下一句會隨朗讀完成度漸進顯示，完成後立即切換
- 當前視覺行使用固定視線錨點；讀到下一行時內容自動上推一行
- 字號、主題、位置、提示頻率及下一句預覽設定
- 手動、鍵盤方向鍵切換字幕作為語音辨識回退

> 瀏覽器的 Web Speech API 需要網絡且支援程度因平台而異。頁面本身不會儲存或上傳稿件；語音辨識服務的資料處理由使用者的瀏覽器供應商決定。

## 本地語言資料

讀音及繁簡處理由專案內置的 `pinyin-pro`、`@pinyin-pro/data`、`ToJyutping` 和 `opencc-js` 完成，無需將稿件傳送至外部翻譯服務。第三方授權文件位於 `vendor/licenses/`。
